        Agent trace

        When you run the agent, it builds each candidate bridge for the chosen model and scores it on held-out clips against controls: swapped audio, no audio, a nearest-example lookup and the text bridge. It installs the best bridge that beats those controls, or installs nothing and says why.

        1. inspect

          Read what the model accepts and whether its weights are open.

        2. plan

          Choose which bridges to try.

        3. fit

          Build each candidate from the labelled examples.

        4. verify

          Score each one on held-out clips against the controls.

        5. decide

          Pick the bridge that beats the controls, or refuse.

        6. install

          Add it to the model's senses, ready for chat.
